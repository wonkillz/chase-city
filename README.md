# CHASE CITY V1.3

Three.js HTML5 로우폴리 자동차 경찰 추격 게임. PC와 iPhone 브라우저용 정적 앱입니다.

```sh
npm ci
npm run dev
```

Node.js 22.12 이상(또는 20.19 이상). ← / → 또는 A / D로 조향하고 P / Escape로 일시정지합니다. 모바일은 좌우 버튼을 누릅니다. 자동 전진하며 드리프트 버튼은 없습니다. START 전에 목표/보상을 확인하고 60초 생존에 도전하세요.

## V1.3

- **조작:** 목표 조향에 지수적으로 접근하고 회전율을 완만하게 조정했습니다. 건물/벤치/경계 충돌에서 플레이어 내구도 피해는 0입니다. 벽 안쪽 속도 성분을 제거해 접선 방향으로 이동하고, 정면으로 막히면 부드럽게 벽 방향으로 빠져나갑니다. 경찰 접촉은 5 피해, 1초 피해 간격으로 조정했습니다. 체포와 차량 파괴 판정은 유지합니다.
- **경찰 경로:** 30 단위 도로 교차점과 10 단위 도로 연결 노드를 A*로 탐색합니다. 확장 충돌 상자를 통과하는 경로/지름길을 제외하고, 약 0.5–0.66초 간격 또는 목적 노드 변경 시 재탐색합니다. 가까운 두 대는 추격, 나머지는 이동 방향을 예측해 차단합니다. 22 이내에서 건물에 가리지 않는 경우에만 직접 접근합니다. 진행 방향이 막히면 정지·재탐색하며 벽을 향해 반복 가속하지 않습니다.
- **추격대:** 초기 4대, 상황에 따라 10초 이후 6초 간격으로 최대 8대까지 증원합니다. 증원/재투입은 플레이어에서 27–48 떨어지고 다른 경찰과 7 이상 간격을 둔 도로 노드에서 이루어집니다. 기존 차량을 순간이동시키지 않습니다. 플레이어 24 / 일반 경찰 20을 유지합니다.
- **사고:** 실제 차량 충격 피해와 연쇄 폭발, 기존 화염·파편·섬광·사운드를 유지합니다. 폭발 수를 맞추는 타이머는 없습니다. 원인을 차량 충돌/벽/연쇄로 기록합니다.
- **후방 효과:** 속도·회전·측면 미끄러짐을 공유하는 로우폴리 먼지와 스키드 자국. 먼지 48개, 자국 64개 고정 풀로 메모리/드로 오브젝트 수를 제한합니다. 속도가 빠르면 먼지가 오래 남고, 급회전 시 방출 빈도와 자국이 증가합니다. 동일 물리량으로 스키드/엔진 사운드를 제어합니다.
- **카메라:** PC는 기존 3/4 시점, 모바일은 약간 넓은 시야로 추격대를 더 쉽게 관찰합니다. 건물 35% 투명화, 완전 복원 및 Web Audio/음소거/미션 UI는 유지합니다.

## 코드 구조

- `src/game/navigation.js`: 도로 그래프, A*, 충돌 없는 연결/지름길, 증원 위치.
- `src/game/police.js`: 추격·차단 역할, 재탐색, 코너 감속, 충격량/내구도.
- `src/game/simulation.js`: 조향/벽 미끄러짐, 4→8대, 충돌·체포·미션 수명주기.
- `src/render/camera.js`: 렌더러와 측정 도구가 공유하는 카메라·화면/가림 검사.
- `src/render/trails.js`: 제한된 후방 먼지/스키드 풀.
- `src/render/scene.js`: 도시·차량·동적 경찰 메시·실제 카메라 측정.
- `src/render/occlusion.js`, `explosions.js`, `src/audio/sound.js`: 투명화, 폭발, 합성 효과음.
- `scripts/pursuit.js`: 정상 좌우 입력으로 60초 추격 반복 측정.

## 검증

```sh
npm test
npx playwright install chromium webkit
npm run test:browser
npm run test:pursuit
npm run build
npm run preview
```

`test:balance`도 `test:pursuit`와 같은 추격 측정입니다. V1.2의 폭발 평균 2–4회 목표를 V1.3의 품질 기준으로 사용하지 않습니다. 추격 거리, 유지 시간, 화면 노출, 벽 충돌과 실제로 보이는 폭발을 별도로 기록합니다.

고정 도시에서 도로 루프 12시드와 급회전/유인 12시드를 각각 60초, 60 Hz로 실행합니다. 위치·내구도 조작이나 강제 폭발을 하지 않습니다. 정상 체포/게임오버 재시작 횟수도 원시 데이터에 포함됩니다. 카메라 노출은 같은 PerspectiveCamera의 투영과 건물 시선 가림 검사 기준(5 Hz)이며 픽셀 전체의 가시 면적은 아닙니다. Node 측정은 건물 AABB로 보수적으로 가림을 추정하고, 브라우저 측정은 실제 병합 건물의 광선 교차와 현재 투명도를 사용합니다.

결과: `docs/pursuit-v1.3.json`, 동일 입력/공유 카메라 기준 V1.2 비교: `docs/pursuit-v1.2-reference.json`. 렌더링 화면과 실제 브라우저 측정은 `TESTING.md`에 기록합니다. WebKit 에뮬레이션은 실제 iPhone 기기 성능 검증을 대체하지 않습니다.

## Cloudflare Pages

프로덕션 브랜치 `main`, 빌드 `npm run build`, 출력 `dist`, Node.js 22. 루트 디렉터리는 저장소 루트입니다. 별도 서버·DB·API 키는 필요하지 않습니다. `wrangler.jsonc`와 정적 응답 헤더를 포함합니다. 배포는 Cloudflare 계정에서 GitHub 저장소를 연결하거나 `npx wrangler pages deploy dist --project-name chase-city`로 진행합니다.

Web Audio는 START 사용자 동작 후 활성화되며 기본 ON입니다. 오디오 미지원에서도 게임은 계속됩니다. 외부 음원은 사용하지 않으며 Google Fonts는 선택적 글꼴입니다. 미션 보상 300 크레딧은 현재 실행에만 지급하고 영구 지갑/차량 구매는 추후 확장 대상입니다.
