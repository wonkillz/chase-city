# CHASE CITY V1.5

Three.js HTML5 로우폴리 자동차 경찰 추격 게임. PC 키보드와 iPhone 터치 브라우저용 정적 앱입니다.

```sh
npm ci
npm run dev
```

Node.js 22.12 이상(또는 20.19 이상). ← / → 또는 A / D로 조향하고 P / Escape로 일시정지합니다. 모바일은 좌우 버튼을 누릅니다. 자동 전진하며 드리프트 버튼은 없습니다. 60초 생존 후 외곽 최종 게이트를 통과하면 도시 탈출과 500 크레딧을 한 번 지급합니다.

## V1.5

- **포위와 체포:** 가까운 경찰이 앞뒤·좌우의 서로 다른 위치를 차단하고 슬롯 도착 시 감속합니다. 저속 포위 차량은 최대 7로 접근하며, 차량 접촉은 분리/반발만 적용합니다. 경찰끼리 피해를 받으려면 충돌 법선 접근 속도와 상대 속도 모두 10 이상, 충돌 전 한 차량의 속도 8 이상이어야 합니다. 고속 실제 사고·내구도·연쇄 폭발은 유지합니다.
- **실제 갇힘 판정:** 근처 경찰 3대 이상, 실제 프레임 이동 속도 3 미만인 경우에 차량 크기를 고려한 24방향 이동 경로를 검사합니다. 직선 출구가 없어도 작은 곡선 통로가 있을 수 있으므로 원형 차량의 이동 공간을 추가 탐색합니다. 탈출 공간이 없을 때만 3초 게이지가 차며, 빠져나오면 초당 2.5초 분량으로 감소합니다.
- **명확한 실패:** 체포는 `BUSTED! / 경찰에게 체포됨`, 내구도 0은 `WRECKED! / 차량 파괴`. 실패 시 물리/추격/주행 소리를 정지하고 UI 실패음을 재생합니다. `RESTART` 한 번으로 새 게임을 시작하며, 성공은 기존 `ESCAPED!`로 구분합니다.
- **전체 도로 통제:** 선명한 노란색과 양면 검정 사선 바리케이드가 도로 폭 전체(11.2)를 차단합니다. 기존 통과 틈은 제거했습니다. 10/20/30/40/50초에 생성하고 2초 전에 경고합니다. 새 장애물을 포함한 도로 그래프에서 다른 도로 우회로를 검증한 배치만 허용합니다. 플레이어·경찰 모두 관통할 수 없으며, 플레이어는 감속/피해 0, 경찰은 강한 충격 피해를 받습니다. 60초에는 남은 바리케이드를 제거해 최종 탈출 경로를 확보합니다.
- **지속 잔해:** 폭발 충격파·화염·파편·차체 튀어 오름 이후 검게 탄 차체, 바닥 파편, 작은 불꽃 3개와 검은 연기 4개를 남깁니다. 착지한 잔해는 실제 장애물이며 A*를 갱신합니다. 좁은 외곽 도로에서도 잔해 주변 보조 경로로 우회합니다.
- **잔해 제한:** 활성 잔해 최대 16개, 최대 수명 30초. 화면 밖의 18초 이상 된 잔해부터 정리합니다. 용량 압박 시 오래된 화면 밖 잔해가 우선이며, 화면 안의 잔해는 1.5초 동안 축소하며 정리합니다. 최대 8개의 정리 중 잔해를 포함해 렌더 풀은 24개 고정입니다. 차체/바닥 조각/불꽃/연기는 지오메트리와 재질을 공유합니다. 재시작 시 물리·화재·메시 풀을 초기화합니다.
- **기존 기능:** A* 추격과 최대 8대 증원, 플레이어 24 / 일반 경찰 22와 일부 26–28 가속, 플레이어 건물 피해 0과 벽 슬라이딩, 건물 전체 35% 투명화·복원, 먼지 48/스키드 64개 고정 풀, 합성 Web Audio·음소거·일시정지, 무작위 외곽 게이트와 방향/거리 안내를 유지합니다.

## 코드 구조

- `src/game/arrest.js`: 차량 공간 검사와 체포 가능 여부.
- `src/game/police.js`, `navigation.js`: 포위/추격 역할, 가속, A*, 잔해 우회 노드와 충돌 피해.
- `src/game/barricades.js`: 일정·전체 폭 배치·다른 도로 우회 검증.
- `src/game/wrecks.js`: 잔해 물리·수명·개수·정리 우선순위.
- `src/game/simulation.js`: 차량 물리, 체포·파괴·미션 수명주기.
- `src/game/escape.js`, `missions.js`: 생존→탈출→최종 게이트 및 보상.
- `src/render/wrecks.js`: 공유 재질/고정 풀의 지속 화재와 탄 차체.
- `src/render/road-events.js`, `scene.js`: 노란 바리케이드, 외곽 게이트, 차량과 도시 렌더링.
- `src/render/occlusion.js`, `trails.js`, `explosions.js`, `src/audio/sound.js`: 기존 투명화·후방 효과·폭발·합성 사운드.


테스트 결과와 PC/모바일 실제 렌더링 화면은 [TESTING.md](TESTING.md)에 기록합니다. `scripts/pursuit.js`, `scripts/escape-check.js`는 정상 좌우 입력만 사용하는 추가 측정 도구입니다. 과거 V1.4 측정 데이터는 `docs/*-v1.4.json`에 보존하며 현재 버전의 수치와 구분합니다. WebKit 에뮬레이션은 실제 iPhone 성능 검증을 대체하지 않습니다.

## Cloudflare Pages

프로덕션 브랜치 `main`, 빌드 `npm run build`, 출력 `dist`, Node.js 22. 루트 디렉터리는 저장소 루트입니다. 별도 서버·DB·API 키는 필요하지 않습니다. `wrangler.jsonc`와 정적 응답 헤더를 포함합니다. Cloudflare에서 GitHub 저장소를 연결하거나 `npx wrangler pages deploy dist --project-name chase-city`를 사용합니다.

Web Audio는 START 사용자 동작 후 활성화되며 기본 ON입니다. 오디오 미지원에서도 게임은 계속됩니다. 외부 음원은 사용하지 않으며 Google Fonts는 선택적 글꼴입니다. 크레딧은 현재 실행의 보상이며 영구 지갑/차량 구매는 추후 확장 대상입니다.
