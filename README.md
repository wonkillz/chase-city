# CHASE CITY V1.2

Three.js로 만든 HTML5 3D 자동차 경찰 추격 게임입니다. 자동 전진하는 차량으로 선명한 색상의 로우폴리 도시, 인도, 공원을 달리며 경찰을 피하세요. 건물과 월드 경계는 통과할 수 없습니다.

## 실행

Node.js 22.12 이상(또는 20.19 이상).

```sh
npm ci
npm run dev
```

브라우저에서 터미널에 표시된 주소를 엽니다. 같은 네트워크의 iPhone에서도 개발 서버의 LAN 주소로 접속할 수 있습니다.

- PC: ← / → 또는 A / D 조향, P / Escape 일시정지
- 모바일: 좌우 버튼을 누른 상태로 조향
- 시작 전 미션 팝업에서 목표와 보상(300 크레딧)을 확인하고 START를 누르세요. 그 전에는 모든 차량과 미션 시간이 정지합니다. 60초 생존에 성공하면 성공 화면이 나타납니다. 보상은 현재 미션 실행에 지급되며 영구 지갑/구매 기능은 추후 확장 대상입니다.
- 플레이어 최고속도는 24, 일반 경찰차는 20 월드 단위/초로 플레이어가 20% 빠릅니다. 경찰은 교차점, 예상 이동 위치와 측면 목표로 포위하며 시간에 따른 속도 증가는 없습니다.
- 경찰끼리 충돌하면 접근 속도에 따른 충격량과 내구도 피해가 적용됩니다. 강한 충돌/누적 손상 시 폭발하며 주변 경찰에게 거리별 피해와 충격을 전달합니다. 차체 튀어 오름, 파편·화염·연기가 표시되고 차체는 3초 후 숨겨지며 5초 후 도로의 먼 지점에서 재투입됩니다.
- 카메라에서 플레이어를 실제로 가리는 건물만 광선 검사 후 불투명도 35%로 부드럽게 전환하고 원래대로 복원합니다. 건물 충돌 판정은 유지됩니다.
- 전진은 자동입니다. 충돌 시 내구도가 감소하며, 내구도 0이면 차량 파괴로 종료됩니다.
- 경찰 2대 이상이 가까이 있고 속도가 낮은 상태로 4초 지속되면 체포됩니다. 거리를 벌리면 체포 게이지가 감소합니다.
- 화면 전환 및 포커스 상실 시 자동 일시정지합니다. 최고 도주 시간은 기기에 저장합니다.

## 구조

```text
src/
  main.js              게임 상태와 고정 시간 간격 루프
  game/config.js       차량과 월드 설정
  game/input.js        키보드, 다중 포인터 입력
  game/simulation.js   차량 운동, 충돌, 체포, 미션 수명주기
  game/police.js       예측/측면 추격, 충돌 충격량과 내구도
  game/missions.js     확장 가능한 미션 정의, 진행, 성공, 보상
  audio/sound.js       Web Audio 효과음, 음소거 및 수명주기
  world/layout.js      도시 배치 및 건물 충돌 해석
  render/scene.js      Three.js 도시, 차량, 카메라, 차체/타이어 움직임
  render/occlusion.js  건물 가림 검사와 투명도 전환/복원
  render/explosions.js 폭발 이벤트의 파편, 화염, 연기
  ui/interface.js      시작, 일시정지, 게임오버, HUD
  style.css            반응형 UI와 안전 영역
public/_headers        Cloudflare 정적 응답 헤더
wrangler.jsonc         Cloudflare Pages 출력 디렉터리
.node-version          빌드 환경 Node.js 22
tests/                  시뮬레이션과 브라우저 회귀 테스트
```

시뮬레이션은 Three.js와 DOM에 의존하지 않습니다. 미션·보석·차량·월드 시스템을 추가할 때 시뮬레이션과 설정/월드 데이터로 상태를 확장하고 렌더러와 UI에서 표시할 수 있습니다. 현재는 한 월드, 한 차량, 경찰 4대와 60초 생존 미션을 제공합니다. `game/missions.js`에 목표/보상/진행/완료 콜백을 가진 정의를 추가하고 시뮬레이션에 관련 상태를 추가하면 보석 수집, 배달, 탈출 미션으로 확장할 수 있습니다. 경찰은 도로 교차점을 경유하고 근접 추격하며, 건물 충돌을 동일하게 적용합니다. 전역 최단 경로 탐색은 사용하지 않습니다.

## 검증

```sh
npm test
npx playwright install chromium webkit
npm run test:browser
npm run build
npm run preview
```

브라우저 테스트는 데스크톱 Chromium과 iPhone 13 크기의 WebKit에서 실행합니다. WebKit 에뮬레이션은 실제 iPhone 기기의 성능·Safari 검증을 대체하지 않습니다. 개발 서버의 `?debug` 파라미터에서만 자동화용 상태 조회가 활성화되며 프로덕션 빌드에서는 제외됩니다.

## Cloudflare Pages 배포

1. Pages에서 GitHub 저장소 `wonkillz/chase-city`를 연결합니다.
2. 프로덕션 브랜치: `main`, 빌드 명령: `npm run build`, 출력 디렉터리: `dist`.
3. 환경 변수 `NODE_VERSION=22`를 설정합니다. 루트 디렉터리는 저장소 루트입니다.
4. 배포하면 HTTPS 주소에서 PC와 iPhone Safari로 플레이할 수 있습니다.

Cloudflare CLI를 사용하는 경우 `npm run build` 후 `npx wrangler pages deploy dist --project-name chase-city`로 배포할 수 있습니다(Cloudflare 로그인 및 프로젝트 생성 필요).

서버·DB·API 키·런타임 환경 변수는 필요하지 않습니다. Three.js는 번들에 포함됩니다. Google Fonts는 선택적 외부 글꼴이며 오프라인에서는 시스템 글꼴로 표시됩니다. 배포는 별도 Cloudflare 계정 연결 후 진행합니다.

## V1.2: 가림, 사고 밸런스, 사운드

- 건물 투명화에서 Three.js의 `OPAQUE` 셰이더가 유지되는 문제를 수정했습니다. `transparent` 전환 시 `needsUpdate`를 적용하고 실제 병합 지오메트리의 시각 경계를 사용합니다. 본체·지붕·창문·문·간판이 하나의 건물 재질로 함께 35%까지 전환되고, 가림이 해제되면 완전 불투명으로 복원됩니다. 건물 충돌 데이터는 변경하지 않습니다.
- 경찰의 예측 추격 목표를 좁혀 경로가 자연스럽게 교차하도록 했습니다. 건물 및 실제 공원 벤치와의 충돌은 법선 방향 충격 속도로 계산합니다. 피해 기준 4 월드 단위/초, 충돌 종류별 0.8초 쿨다운, 충격 강도에 따른 비선형 피해를 적용합니다. 정지한 차를 벽에 계속 밀거나 가벼운 접촉을 빠르게 반복하는 경우 즉시 파괴되지 않습니다.
- 폭발에는 더 밝은 화염·중심 섬광·충격파 링을 추가했습니다. 폭발은 내구도/충돌로만 발생하며 별도의 빈도 타이머나 강제 폭발은 없습니다. 경찰 재투입과 연쇄 폭발은 유지됩니다.
- `src/audio/sound.js`는 Web Audio로 엔진, 거리별 사이렌, 급회전 스키드, 충격별 충돌, 폭발, 성공/실패 음을 직접 합성합니다. 외부 음원은 없습니다. START/계속하기 사용자 동작에서 오디오를 활성화하고, 기본 소리 ON 및 HUD 음소거를 제공합니다. 일시정지 시 주행음과 효과음을 끄며 게임오버에서는 주행음을 끄고 짧은 결과음만 재생합니다. 음량 제한·컴프레서·동시 효과음 6개 제한을 적용합니다. 오디오가 없거나 초기화에 실패해도 게임은 계속 실행됩니다.

### 사고 빈도 재현

```sh
npm run test:balance
```

혼합 시드 LCG로 조향 방향·회전 시점·도로 루프를 선택하여 60개 시드에서 각각 3,600프레임(60초, 고정 60 Hz)을 주행합니다. 정상 좌우 입력만 사용하며 차량 위치·내구도를 조작하거나 폭발을 호출하지 않습니다. 최종 측정은 **3.067대/60초**(연쇄 포함 폭발 차량 수), 개별 범위 0–9대, 목표 평균 2–4대에 해당합니다. 초기 40개 시드는 평균 3.175대, 추가 20개는 2.85대이며 최종 측정에서 사망/체포 재시작은 없었습니다. 같은 초기 40개 입력 시드의 V1.1은 평균 1.975대였습니다. 이 수치는 해당 자동 운전 정책에서의 결과이며 모든 사람의 운전 경로에서 보장되는 빈도는 아닙니다.

원시 데이터: `docs/balance-v1.2.json`, 기준 버전 데이터: `docs/balance-v1.1-reference.json`. 평균이 목표 범위를 벗어나면 명령이 실패 코드로 종료합니다. 테스트는 정상 사망/체포가 발생하면 재시작하고 횟수를 기록하도록 되어 있으며, 최종 데이터의 재시작은 0입니다.

렌더링 회귀 검사는 재질 값뿐 아니라 GPU 프레임버퍼에서 플레이어 표시 픽셀을 비교합니다. V1.1 방식의 음성 대조군, 수정 후 차량 표시, 완전 복원까지 검사합니다. PC Chromium·iPhone 크기 WebKit에서 오디오 출력 PCM, START 전 미생성, 음소거·일시정지·미지원 환경도 검증합니다.
