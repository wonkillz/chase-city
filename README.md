# CHASE CITY V1.6

Three.js HTML5 자동차 경찰 추격 게임. 이번 버전은 V1.5의 실제 체포 실패와 잔해 소멸을 수정하며 새로운 게임 콘텐츠를 추가하지 않습니다.

```sh
npm ci
npm run dev
```

Node.js 22.12 이상(또는 20.19 이상). ← / → 또는 A / D로 조향하고 P / Escape로 일시정지합니다. 모바일은 좌우 버튼을 누릅니다. 자동 전진하며 드리프트 버튼은 없습니다. 60초 생존 후 외곽 최종 게이트를 통과하면 `ESCAPED!`와 500 크레딧을 한 번 지급합니다.

## 수정 내용

- **실행 내 영구 잔해:** 30초 수명, 화면 밖 18초 정리, 개수 초과 시 오래된 잔해 삭제를 제거했습니다. 차체/불꽃/검은 연기/충돌체는 현재 실행 동안 같은 ID와 위치로 유지합니다. 경찰차 재투입과 잔해 수명주기를 분리하고, 결과 화면에서는 마지막 상태를 동결합니다. RESTART에서만 데이터를 비웁니다.
- **렌더링 관리:** 처음 화면에 들어온 잔해에 공유 재질/지오메트리의 렌더 슬롯을 할당합니다. 초기 슬롯 16개는 최대치가 아니며 필요하면 확장합니다. 실행 중 할당한 슬롯을 다른 잔해로 재사용하지 않습니다. 화면 밖에서는 장면에서 분리해 렌더·행렬/이펙트 갱신을 생략하며, 다시 보이면 같은 객체를 붙입니다. 먼 이펙트는 5–10 Hz로 갱신합니다. 데이터와 캐시는 실행 중 누적되며 재시작 시 슬롯은 새 실행에서 재사용할 수 있습니다.
- **실제 체포:** 3대 이상 가까운 경찰과 건물/바리케이드/잔해를 대상으로 차체 전체(2.1 × 3.6 및 작은 여유)의 통과·회전 공간을 검사합니다. 작은 중심 원만 지나는 틈, 옆으로 이동하거나 즉시 방향을 바꾸는 경로를 탈출구로 인정하지 않습니다. 실제 주행 가능한 출구가 없으면 포위망 안에서 밀려 이동해도 게이지가 차고 약 3초에 BUSTED 처리합니다. 포위망을 벗어나거나 주행 가능한 출구가 열리면 빠르게 감소합니다.
- **포위 안정화:** 포위 진입 시 속도·접근 속도를 제한하고, 플레이어가 조향할 때 포위 대형까지 계속 회전하던 동작을 고정합니다. 저속 경찰 접촉 피해는 0입니다. 가까운 저속 포위 차량의 연쇄 폭발 피해와 충격을 줄이고 즉사시키지 않으며, 고속 추격 충돌/폭발과 일반 연쇄 폭발은 유지합니다.

기존 A* 추격·최대 8대 증원, 노란 전체 폭 바리케이드/우회로, 플레이어 건물 피해 0과 벽 슬라이딩, 건물 투명화, 먼지·스키드, Web Audio, 음소거·일시정지, 탈출 미션·보상을 유지합니다.

## 검증

```sh
npm test
npx playwright install chromium webkit
npm run test:browser
node scripts/reproduce-v16.js
npm run build
npm run preview
```

`reproduce-v16.js`는 기본 시작 위치에서 처음 5초 직진 후 우회전 입력만 유지합니다. 경찰 배치·내구도·최고속도·증원·미션을 변경하지 않고 실제 AI 포위/체포 시간 기록을 출력합니다. 브라우저 검사는 같은 입력을 실제 requestAnimationFrame 게임 루프에서 실행합니다. 별도의 잔해 검사만 충돌 fixture와 고정 60 Hz 진행을 사용합니다.

재현 경로, 실제 화면과 시간 기록, 테스트 결과는 [TESTING.md](TESTING.md)에 있습니다. 과거 버전 수치는 `docs/*-v1.5.json` 등 버전별 파일에 보존합니다. 모바일 WebKit 에뮬레이션은 실제 iPhone 성능 검증을 대체하지 않습니다.

## 관련 코드

- `src/game/arrest.js`: 차체 전체 및 조향을 고려한 탈출 공간 검사.
- `src/game/simulation.js`, `police.js`: 체포 진행, 밀림/상대 이동 기록, 포위 속도 및 상황별 폭발 피해.
- `src/game/wrecks.js`, `src/render/wrecks.js`: 실행 내 영구 데이터, 착지 장애물, 확장 렌더 캐시/거리별 이펙트 갱신.
- `src/game/navigation.js`, `barricades.js`, `escape.js`, `missions.js`: 기존 경로 탐색·도로 통제·탈출.
- `src/render/scene.js`, `occlusion.js`, `trails.js`, `explosions.js`, `src/audio/sound.js`: 기존 렌더링·투명화·차량 효과·사운드.
- `scripts/reproduce-v16.js`, `tests/v16.test.js`, `tests/browser/v16.spec.js`: 정상 시작 재현 및 장시간/화면 밖/확장/종료 검증.

## Cloudflare Pages

프로덕션 브랜치 `main`, 빌드 `npm run build`, 출력 `dist`, Node.js 22. 루트 디렉터리는 저장소 루트입니다. 별도 서버·DB·API 키는 필요하지 않습니다. `wrangler.jsonc`와 정적 응답 헤더를 유지합니다.

Web Audio는 START 사용자 동작 후 활성화되며 기본 ON입니다. 오디오 미지원에서도 게임은 계속됩니다. 외부 음원은 사용하지 않으며 Google Fonts는 선택적 글꼴입니다. 크레딧은 현재 실행의 보상이며 영구 지갑은 후속 확장 대상입니다.
