# CHASE CITY V1.4

Three.js HTML5 로우폴리 자동차 경찰 추격 게임. PC와 iPhone 브라우저용 정적 앱입니다.

```sh
npm ci
npm run dev
```

Node.js 22.12 이상(또는 20.19 이상). ← / → 또는 A / D로 조향하고 P / Escape로 일시정지합니다. 모바일은 좌우 버튼을 누릅니다. 자동 전진하며 드리프트 버튼은 없습니다. START 전에 목표/보상을 확인하고 60초 생존 후 외곽 최종 게이트를 통과해 도시를 탈출하세요.

## V1.4

- **추격:** 플레이어 최고속도 24, 일반 경찰 22. 일부 추격 차량만 직선·후방·시야 확보 조건에서 26–28로 약 3초 가속합니다. 코너, 장애물 또는 근접 시 가속이 끝나며 쿨다운을 둡니다. 가까운 두 대는 직접 추격, 다른 차량은 이동 방향을 예측해 A*로 우회·차단합니다. 탈출 도로도 같은 그래프에 연결합니다.
- **점진적 증원:** 0/10/20/30/40초에 목표 대수 4/5/6/7/8. 가까운 안전한 도로에만 신규/교대 차량을 투입하고, 기존 차량을 순간이동시키지 않습니다. 빈 도로가 없으면 배치를 기다립니다.
- **충돌:** 보이는 차체 크기의 회전 직사각형 SAT 판정, 실제 접근 속도에 따른 내구도 피해와 반발. 강한 차량 충돌 약 2회, 바리케이드/벽 충돌 약 3회에 파괴됩니다. 가벼운 접촉은 피해 문턱과 0.8초 쿨다운으로 보호합니다. 차량 충돌에 밀려 장애물에 닿는 경우도 처리하며, 경로 검사로 벽 돌진은 방지합니다. 화염·파편·연기·차체 튀어 오름·합성 사운드·연쇄 폭발·재투입을 유지합니다. 폭발 횟수를 맞추는 강제 이벤트는 없습니다.
- **도로 통제:** 8/18/28/38/48초 경고, 10/20/30/40/50초에 실제 도로 위 전방 바리케이드. 건물·벤치·차량과 겹치지 않는 위치를 선택하고, 폭 5의 통과 틈과 도로 우회로를 검사합니다. 동적 장애물을 A*에 반영하며 지나간 장애물은 3초 후, 남은 장애물도 14초 후 제거합니다. 플레이어는 감속만 받고 경찰은 충격 피해를 받습니다.
- **최종 탈출:** 60초에 `ESCAPE ROUTE OPEN!`을 표시하고 추격을 계속합니다. 도로에 연결된 외곽 후보 12곳 중 무작위 한 곳에 녹색 게이트·빛 기둥·도시 밖 도로를 엽니다. 재시작 시 직전 후보는 제외합니다. 방향 화살표/거리로 안내하며, 기존 바리케이드는 제거해 탈출 경로를 확보합니다. 최종 게이트를 바깥 방향으로 통과해야 `ESCAPED!`와 500 크레딧을 한 번 지급하고 추격·타이머를 정지합니다. 탈출 전 체포·파괴는 실패입니다.
- **기존 기능:** 건물 전체 35% 투명화/복원, 쉬운 좌우 조향, 플레이어 건물 피해 0, 모서리 벽 슬라이딩, 먼지 48개/스키드 64개 고정 풀, 엔진·사이렌·충돌·폭발·UI 합성 사운드, 음소거·일시정지·모바일 터치를 유지합니다. 드리프트 버튼은 없습니다.

## 코드 구조

- `src/game/navigation.js`: 도로 그래프, A*, 충돌 없는 연결/지름길, 증원 위치.
- `src/game/police.js`: 추격·차단 역할, 재탐색, 코너 감속, 충격량/내구도.
- `src/game/simulation.js`: 조향/벽 미끄러짐, 4→8대, 충돌·체포·미션 수명주기.
- `src/game/barricades.js`: 일정, 안전 배치/통과 틈, 제거 및 경로 무효화.
- `src/game/escape.js`, `missions.js`: 외곽 도로 후보, 경계/게이트, 생존→탈출→완료와 보상.
- `src/render/road-events.js`: 바리케이드 풀, 외곽 도로/녹색 게이트, 방향 안내.
- `src/render/camera.js`: 렌더러와 측정 도구가 공유하는 카메라·화면/가림 검사.
- `src/render/trails.js`: 제한된 후방 먼지/스키드 풀.
- `src/render/scene.js`: 도시·차량·동적 경찰 메시·실제 카메라 측정.
- `src/render/occlusion.js`, `explosions.js`, `src/audio/sound.js`: 투명화, 폭발, 합성 효과음.
- `scripts/pursuit.js`: 정상 좌우 입력으로 60초 추격 반복 측정.

## 검증

```sh
npm test
npx playwright install chromium webkit
npm run test:browser
npm run test:pursuit
npm run test:escape
npm run build
npm run preview
```

`test:balance`도 `test:pursuit`와 같은 추격 측정입니다. 폭발 평균 횟수만으로 품질을 판단하지 않습니다. 추격 거리, 유지 시간, 화면 노출, 벽 충돌과 실제로 보이는 폭발을 별도로 기록합니다.

고정 도시에서 도로 루프 12시드와 급회전/유인 12시드를 각각 60초, 60 Hz로 실행합니다. 위치·내구도 조작이나 강제 폭발을 하지 않습니다. 정상 체포/게임오버 재시작 횟수도 원시 데이터에 포함됩니다. 카메라 노출은 같은 PerspectiveCamera의 투영과 건물 시선 가림 검사 기준(5 Hz)이며 픽셀 전체의 가시 면적은 아닙니다. Node 측정은 건물 AABB로 보수적으로 가림을 추정하고, 브라우저 측정은 실제 병합 건물의 광선 교차와 현재 투명도를 사용합니다.

결과와 원시 데이터/브라우저 스크린샷은 `TESTING.md` 및 `docs/pursuit-v1.4.json`, `docs/escape-v1.4.json`에 기록합니다. `test:escape`는 위치·내구도를 수정하지 않는 정상 좌우 입력으로 전체 생존/탈출 단계를 실행하며 실패와 시간 초과도 보고합니다. WebKit 에뮬레이션은 실제 iPhone 기기 성능 검증을 대체하지 않습니다.

## Cloudflare Pages

프로덕션 브랜치 `main`, 빌드 `npm run build`, 출력 `dist`, Node.js 22. 루트 디렉터리는 저장소 루트입니다. 별도 서버·DB·API 키는 필요하지 않습니다. `wrangler.jsonc`와 정적 응답 헤더를 포함합니다. 배포는 Cloudflare 계정에서 GitHub 저장소를 연결하거나 `npx wrangler pages deploy dist --project-name chase-city`로 진행합니다.

Web Audio는 START 사용자 동작 후 활성화되며 기본 ON입니다. 오디오 미지원에서도 게임은 계속됩니다. 외부 음원은 사용하지 않으며 Google Fonts는 선택적 글꼴입니다. 완전 탈출 보상 500 크레딧은 현재 실행에만 지급하고 영구 지갑/차량 구매는 추후 확장 대상입니다.
